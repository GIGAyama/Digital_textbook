# 📚 デジタル教科書メーカー (Digital Textbook Maker)

学校現場の先生のために開発された、**完全無料・サーバー（データベース）不要**のデジタル教科書＆プリント作成・共有Webアプリです。

PDFファイルをブラウザに読み込ませるだけで、ペンやマーカーによる書き込み、ふせんの貼り付け、豊富な「教育用スタンプ」の配置が可能になります。さらに、**WebRTC（P2P通信）技術**を採用しており、クラウドサーバーを経由せずに先生の端末から児童生徒の端末へ直接データを共有（配布）できます。

## ✨ 主な機能

### 1. 充実した書き込み・教育ツール

*   **基本ツール**: ペン、マーカー、消しゴム、テキスト入力、ふせん、リンク・音声の埋め込み
    
*   **図形描画**: 四角、円、直線、矢印
    
*   **豊富なプリセットスタンプ**:
    
    *   【評価】💮 はなまる、💯 100点、👍 いいね など
        
    *   【国語】縦書きテキスト（いつ、どこで、はじめ・中・おわり、主語・述語など）
        
    *   【算数】1/10/100/1000のブロック、位取り表、筆算枠、2D図形、3D立体図形（透明感のある美しいデザイン）、リアルな分度器・三角定規
        
    *   【理社/生活】天気、地図記号、時計、実験器具など
        
*   **マイスタンプ機能**: 好きな文字・色・枠の形を組み合わせて自分だけのスタンプを作成・保存可能。
    

### 2. P2P（端末間直接通信）によるデータ共有

*   **サーバー代ゼロ・情報漏洩リスクゼロ**: Firebaseなどのクラウドデータベースを使わず、[PeerJS (WebRTC)](https://peerjs.com/ "null") を使用して先生の端末と児童生徒の端末を直接つなぎます。
    
*   **QRコード・URLで一発共有**: 「共有する」ボタンを押すと、専用のQRコードとURLが自動生成されます。児童生徒がこれを読み取るだけで、PDFと書き込みデータがまるごと瞬時にダウンロードされます。
    

### 3. バックアップ／別端末への移行（Googleドライブ等を利用）

*   **ワンクリックでJSONバックアップ**: ホーム画面の「バックアップを書き出す」ボタンで、読み込んだPDF・書き込み・マイスタンプをまとめて1つのJSONファイルにダウンロードできます。
    
*   **Googleドライブで端末間同期**: 書き出したJSONファイルをGoogleドライブ（Google アカウント）にアップロードしておけば、別の端末でログインしてダウンロードし、「バックアップを取り込む」から選択するだけでデータをまるごと復元できます。
    
*   **追加 / 置き換えを選べる**: 取り込み時に「追加で取り込む（既存データは残す）」と「置き換える（既存データを破棄）」を選べるので、複数端末の内容を統合したり、まっさらな状態にリセットしたりできます。
    

### 4. PWA対応（アプリとしてインストール可能）

*   **Chromeからワンクリックでインストール**: アプリを開いた状態で、アドレスバー右端のインストールアイコン（またはメニューの「アプリをインストール」）をクリックすると、デスクトップ・ホーム画面に独立したアプリとして追加できます。
    
*   **オフライン起動**: Service Workerがアプリ本体と外部ライブラリ・フォントをキャッシュするため、一度読み込めばインターネットに接続できない環境でも起動して書き込みの続きができます（P2P共有・QRリンク先の閲覧はオンライン時のみ）。
    
*   **自動アップデート**: 新しいバージョンが公開されると、次回アクセス時に自動で更新されます。
    

### 5. 学校現場に特化した便利機能

*   **高精度QRコードリーダー**: アプリ内からプリントに印字されたQRコードをクリック（またはドラッグで範囲選択）するだけで、内蔵の解析エンジンがリンクを読み取り、即座にWebサイトを開きます。
    
*   **タイマー＆ストップウォッチ**: 画面の隅に表示しておけるフローティングタイマーを内蔵。授業の活動時間を測るのに最適です。
    
*   **完全オフライン動作（ローカル保存）**: 読み込んだPDFや書き込みデータはブラウザの `IndexedDB` に自動保存されます。一度開いた教科書は、次回以降オフラインでもすぐに続きから開くことができます。
    
*   **キーボードショートカット**: 矢印キーでのページめくりやズーム、`Ctrl+Z` でのUndo/Redo、各種ツールの素早い切り替えに対応。
    

## 🛠 技術スタック

*   **Frontend Framework**: React
    
*   **Styling**: Tailwind CSS
    
*   **Icons**: Lucide React
    
*   **Canvas Drawing**: Fabric.js (v5)
    
*   **PDF Rendering**: PDF.js
    
*   **P2P Networking**: PeerJS
    
*   **Local Storage**: idb-keyval (IndexedDB)
    
*   **QR Code parsing**: BarcodeDetector API / jsQR
    
*   **QR Code generation**: qrcode.js
    
*   **PWA / Offline**: vite-plugin-pwa (Workbox)
    

## 🚀 セットアップ・起動方法

このアプリケーションはバックエンドサーバーを必要とせず、静的ファイルのみで動作します（GitHub PagesやVercel、Cloudflare Pagesなどにデプロイ可能です）。

### ローカルでの開発環境構築（Viteを使用する場合）

1.  リポジトリをクローンします。
    
    ```
    git clone [https://github.com/yourusername/digital-textbook-maker.git](https://github.com/yourusername/digital-textbook-maker.git)
    cd digital-textbook-maker
    ```
    
2.  パッケージをインストールします。
    
    ```
    npm install
    ```
    
3.  開発サーバーを起動します。
    
    ```
    npm run dev
    ```
    
4.  ブラウザで `http://localhost:5173` にアクセスします。
    

*(※本コードはCDNを利用して外部ライブラリを読み込む構成になっているため、インターネット接続環境下での初回ロードが必要です。)*

## 🔐 セキュリティとプライバシーについて

*   本アプリは、ユーザーがアップロードしたPDFや書き込みデータを**外部のクラウドサーバーに一切送信・保存しません**。
    
*   全てのデータはユーザーのデバイス上（ブラウザのIndexedDB）にのみ保存されます。
    
*   共有機能（P2P通信）を利用する際のシグナリング（接続先の仲介）にのみPeerJSのパブリックサーバーを使用しますが、実際のデータ通信は端末間で直接（エンドツーエンド暗号化で）行われます。
