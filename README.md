# **📖 デジタル教科書メーカー (Digital Textbook)**

**PDFや画像を「ペタっと」貼って、自由自在に書き込める。** **GIGAスクール端末のための、シンプルで高機能なデジタル教科書アプリ。**

## **💡 概要 (Overview)**

「配布されたPDFのプリントや教科書を、タブレットで快適に扱いたい」

そんな教育現場の声から生まれたWebアプリケーションです。

Googleスライドと連携し、PDFを一括で背景画像として取り込み、ブラウザ上で**書き込み、スタンプ、付箋、拡大縮小**などがスムーズに行えます。

プログラミングの知識がない先生でも、Googleアカウントさえあれば無料で導入・運用が可能です。

## **✨ 主な機能 (Features)**

### **📚 デジタル教科書ビューワー**

* **PDF/画像インポート**: ローカルのPDFファイルやGoogleドライブ内の画像を自動でスライド化。  
* **爆速ページめくり**: 独自キャッシュ機能により、待機時間ゼロの快適な操作感を実現。  
* **マルチデバイス対応**: タッチ操作（ピンチイン・アウト、スワイプ）とマウス操作の両方に対応。

### **✏️ 編集・描画ツール**

* **ペン・マーカー**: 筆圧感のある描き心地（Fabric.js採用）。  
* **図形描画**: 直線、矢印、四角、円をきれいに描画。  
* **高機能ふせん**: 色を選んでペタっと貼り付け。文字サイズは自動調整。  
* **テキスト入力**: 縦書き・横書きに対応。

### **💮 スタンプ機能**

* **教科別プリセット**: 国語（縦書き構成図）、算数（ブロック、筆算枠）、評価印などを標準搭載。  
* **マイスタンプ作成**: 好きな文字や絵文字、形、色を組み合わせてオリジナルスタンプを作成・保存可能。

### **🏫 授業支援ツール**

* **QRコード読み取り**: 画面上のQRコードを囲むだけでリンクを認識し、自動で開きます。  
* **タイマー＆ストップウォッチ**: 授業中のタイムキーピングに。音とフラッシュでお知らせ。  
* **マルチメディア**: 外部Webサイトへのリンクボタンや、音声ファイルの再生ボタンをページ内に埋め込み可能。

### **💾 データ管理**

* **自動保存**: 書き込み内容はGoogleスライドを汚さず、連携したスプレッドシートに自動バックアップ。  
* **レジューム機能**: 前回開いていたページを自動で記憶し、続きからすぐに再開。

## **🛠️ 技術スタック (Tech Stack)**

* **Backend**: Google Apps Script (GAS)  
* **Frontend**: HTML5, CSS3, JavaScript (Vanilla)  
* **Libraries**:  
  * [Bootstrap 5](https://getbootstrap.com/) (UI Framework)  
  * [Fabric.js](http://fabricjs.com/) (Canvas manipulation)  
  * [PDF.js](https://mozilla.github.io/pdf.js/) (PDF rendering)  
  * [jsQR](https://github.com/cozmo/jsQR) (QR code scanning)  
  * [SweetAlert2](https://sweetalert2.github.io/) (Modal dialogs)  
* **Design Font**: Zen Maru Gothic (Google Fonts)

## **🚀 導入手順 (Installation)**

このアプリは、Googleスライドの「コンテナバインドスクリプト」として動作します。

1. **Googleスライドの作成**:  
   * 新規Googleスライドを作成し、名前を付けます（例：「My教科書」）。  
2. **スクリプトエディタを開く**:  
   * メニューの 拡張機能 \> Apps Script をクリックします。  
3. **ファイルの作成**:  
   * 以下の4つのファイルを作成し、リポジトリ内の同名ファイルの中身をコピペしてください。  
     * コード.gs (Server-side)  
     * index.html (Main UI)  
     * css.html (Styles)  
     * js.html (Client-side Logic)  
4. **デプロイ**:  
   * 右上の「デプロイ」 \> 「新しいデプロイ」をクリック。  
   * 種類の選択: 「ウェブアプリ」  
   * 次のユーザーとして実行: 「自分」  
   * アクセスできるユーザー: 「Googleアカウントを持つ全員」（または組織内）  
   * 「デプロイ」ボタンを押し、発行された **ウェブアプリURL** をコピーします。  
5. **初回セットアップ**:  
   * URLにアクセスすると初期画面が表示されます。  
   * 「システム初期化」ボタンを押すと、データ保存用のスプレッドシートが自動生成され、準備完了です。

## **📖 使い方 (Usage)**

1. **教科書の取り込み**:  
   * 初期画面で「PDFを選択」または「GoogleドライブのフォルダURL」を入力します。  
2. **授業での活用**:  
   * **書く**: ツールバーからペンを選んで書き込み。  
   * **消す**: 消しゴムまたはゴミ箱ボタン（全消去）。  
   * **スタンプ**: スタンプボタンからサイドパネルを開き、ドラッグ＆ドロップ感覚で配置。  
   * **拡大**: ピンチアウトまたはズームボタン。  
   * **QR**: QRモードにしてコードを囲むとリンク先にジャンプ。  
3. **終了**:  
   * そのままブラウザを閉じてOK（自動保存されています）。次回アクセス時は続きから始まります。

## **⚠️ 注意事項**

* Google Workspace for Education環境での利用を想定していますが、個人のGoogleアカウントでも動作します。  
* 大量のページ（数百ページ以上）を一括で取り込むと、処理に時間がかかる場合があります。
