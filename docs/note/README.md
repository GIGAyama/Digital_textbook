## note への貼りかた

1. **タイトル欄**: 記事本文の1行目（`# 教室で…`）の `# ` を除いた文字列を、note のタイトル欄に貼ります。本文欄には入れません。
2. **本文欄**: 2行目以降（`## 🏫 はじめに` から末尾まで）をそのまま本文欄に貼ります。`##` の見出しは自動的に見出しとして認識され、note が目次を自動生成します。
3. **画像のアップロード**: 画像は自動で挿入されません。本文中の `![...](images/xx-....png)` の位置で、下の対応表を見ながら手動で画像をアップロードしてください。
4. **キャプション欄**: 画像の直下にある1行の説明文は、note の画像キャプション欄へ移してください（本文内に残しても読めますが、キャプション欄に入れたほうが見栄えが整います）。
5. **ハッシュタグ**: 記事末尾の `## 🏷 ハッシュタグ` の下に並んでいるタグを、note のタグ設定欄に登録してください。
6. **公開前確認**: 公開前に、アプリの URL（https://digital-textbook.giga-school.com/）が開けることを確認してください。
